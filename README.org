* ZyEmacs v3.0
#+html: </div>

Zyxir's lightweight and elegant Emacs config.  Key features include:

- PKM & GTD :: Personal Knowledge Magagement and Getting Things Done workflows powered by Org-mode.
- Minimalism :: Only essential packages and UI elements.
- macOS Optimized :: Supports Emacs version 30 and newer on macOS.

** Installation

~git clone~ this repository to ~$HOME/emacs.d~.  That's all.

** Customization

Menu→Options→Customize Emacs, see options begin with "[ℤ]".
